NVO RESTAURANT

WEBSITE + CUSTOMER GROWTH + CONTENT ADMINISTRATION SYSTEM

PRODUCT OBJECTIVE

Build a premium, modern, highly responsive restaurant website and customer-growth platform for NVO Restaurant.

This must NOT be treated as a simple restaurant brochure website.

The system should have three major purposes:

1. Attract new customers
2. Convert visitors into customers
3. Help NVO continuously publish content, promotions and events while tracking customer activity

The website must be visually impressive enough to represent a premium restaurant while also functioning as a practical business system.

The final product should feel like a professionally designed restaurant brand combined with a lightweight customer-acquisition platform.

---

1. BRAND DIRECTION

Primary Colors

NVO's official website color direction:

* Blue
* White
* Gold

Use these colors elegantly rather than simply filling the entire website with blue.

Suggested visual hierarchy:

* Deep/premium blue → primary background, navigation, major sections
* White → main content/backgrounds/readability
* Gold → premium accents, buttons, highlights, borders, icons and important calls-to-action

Gold should be used strategically so that it feels premium rather than excessive.

The overall feeling should be:

Premium + Modern + Elegant + Welcoming + Appetizing + Trustworthy

Avoid making the website look like a generic restaurant template.

Example:

"nvo.com/r/ABC123"

* Share through available device sharing
* Copy referral code

The system records the referral.

The referred person should receive an available referral offer/coupon according to the rules configured by NVO.

12. REFERRAL COUPON EXPIRATION

NVO specifically wants the referral opportunity to be time-sensitive.

Example:

Customer shares link.

Friend opens it.

A countdown begins:

Your referral offer expires in 05:00

During the valid period, the referred visitor can claim the offer.

The system should generate a unique coupon/token for the referred visitor.

Example:

"NVO-7K29X"

The user should be able to:

* Save coupon
* Copy coupon
* Download/save coupon as an image or digital card
* Use it later according to NVO's configured rules

IMPORTANT:

The five-minute timer should control claiming/activating the referral offer, unless NVO specifically configures the actual coupon expiration differently.

Do not automatically assume that the coupon itself must expire five minutes after generation.

Admin should be able to configure:

* Referral link claim window
* Coupon validity
* Discount percentage
* Minimum order
* Usage limit

62. MOST IMPORTANT SUCCESS CRITERIA

The project is NOT complete simply because:

* The homepage looks beautiful
* The animations work
* The menu exists
* The admin dashboard exists

It is complete when the entire journey works.

A customer should be able to:

Discover → Visit → Browse → Add to cart → Apply coupon → Confirm → Open WhatsApp

And NVO staff should be able to:

Log in → Add meal → Create promotion → Create post → Generate captions → Publish → Schedule → View analytics

And an existing customer should be able to:

Refer friend → Generate unique referral → Friend opens link → Claim offer → Save coupon → Order

And NVO should be able to:

Publish once → Website updates → Authorized social channels receive platform-specific content
